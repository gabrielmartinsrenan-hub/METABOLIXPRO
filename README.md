# Metabolix Pro | Supplement Landing Page

A concept landing page for a fictional dietary supplement, built to practice conversion-oriented layouts, product presentation and front-end fundamentals.

> **Disclaimer:** Metabolix Pro is a fictional product created for portfolio purposes only. The health claims, ratings and customer reviews shown on the page are placeholder content and do not refer to a real product or real customers.

## About the project

Metabolix Pro is a single-page website that presents a clinical, science-driven supplement brand. The goal was to design a clean, trustworthy interface that guides visitors from the headline to the purchase button, using clear hierarchy, strong typography and a restrained color palette of deep green and amber.

## Features

- Responsive navigation bar with links to the main sections: Science, Ingredients, Estimator, Results and FAQ
- Shopping cart icon with item counter and an "Order Now" call-to-action
- Customer rating badge (4.9/5) to build social proof
- Hero section with a bold headline and highlighted keywords
- Benefit cards: Thermogenic Fat Burn, Appetite Control and Clean All-Day Energy
- Product bottle illustration built for the page, with a floating info card
- Clean clinical visual identity in deep green, amber and soft neutral tones

## Built with

- **HTML5**: semantic page structure
- **CSS3**: layout, custom styling, responsive design
- **JavaScript**: interactivity and dynamic behavior
- **Git and GitHub**: version control and hosting

## What I practiced

- Structuring a landing page around a single conversion goal
- Building visual hierarchy with typography, spacing and color
- Creating UI components such as cards, badges and a navigation bar
- Presenting a product visually without relying only on photos
- Writing and organizing a project with Git, and documenting it on GitHub

## Getting started

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/gabrielmartinsrenan-hub/YOUR-REPOSITORY-NAME.git

# Enter the project folder
cd YOUR-REPOSITORY-NAME
```

Then open `index.html` in your browser, or use the **Live Server** extension in VS Code (right-click `index.html` and choose **Open with Live Server**).

## Deploy

The site can be published for free with **GitHub Pages**: in the repository, go to **Settings > Pages**, select the `main` branch and the `/ (root)` folder, and save.
